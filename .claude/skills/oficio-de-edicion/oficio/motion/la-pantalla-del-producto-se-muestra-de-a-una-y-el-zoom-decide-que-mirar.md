## Qué decide quien lo enseña

Decide que cada escena de producto es una sola tarjeta o ventana, con un único elemento activo (una fila que se selecciona, un botón que cambia de estado, un pin que cambia de color). La pantalla va dentro de un marco de esquinas redondeadas y borde fino, y se desliza entera. Para llevar la vista a un detalle se hace zoom y se desenfoca o se atenúa el resto, no se dibujan flechas ni recuadros. El cursor aparece para el primer toque o para el botón de acción y después se deja al zoom. Las pantallas se rehacen en limpio para el video en vez de usar capturas crudas.

## Por qué

Una pantalla de software tiene decenas de elementos y el espectador no sabe a cuál mirar en dos segundos. Reducir la escena a un elemento activo y mover la cámara hacia él hace la elección por él. Las capturas crudas con menús pequeños se vuelven ilegibles al comprimirse o verse en un teléfono, algo que dos fichas señalan como defecto. La cifra de que la pantalla debe ocupar al menos el 60 % del ancho es una sugerencia de una de las fichas, no una medición: se toma como punto de partida.

## Funciona

- Una tarjeta por escena con un solo elemento activo.
- Un zoom suave al detalle que importa, con el resto desenfocado.
- Un marco con borde fino que contiene la captura y se desliza entero.
- Un botón en primer plano, con cursor, como remate de cada bloque.
- Rehacer las pantallas con los datos pensados para el video.

## No funciona

- Capturas del producto reales, pequeñas y con texto ilegible a tamaño de video.
- Flechas, círculos y anotaciones que le dicen al ojo lo que el encuadre debió decirle.
- Mostrar la pantalla completa del producto con todos sus paneles a la vez.
- Un cursor que se pasea por toda la pantalla.
- La app entera, plana y quieta, con un zoom encima. Cada función se cuenta con piezas sueltas de la interfaz, grandes, que flotan, se arman y se mueven, y se siente viva, no como una captura de presentación.

## Cuándo no aplica

- Si el producto es la pantalla densa (un tablero con muchos datos) y la idea es la densidad misma, se muestra completa unos segundos antes del zoom.
- En un tutorial de pasos que el espectador va a repetir, el cursor y las anotaciones sí se necesitan.
- Si el cliente exige capturas reales de su sistema, se recortan y se amplían, y se cuida la legibilidad.
