# Formato: tutorial con grabación de pantalla

Video donde se ve cómo se hace algo en una pantalla (una app, una terminal, un editor).

## Pasos
1. **Qué se graba:** una sola ventana limpia, con el recorrido escrito antes, sin tocar lo que el dueño tenga abierto. El estilo dice con qué se graba.
2. **Pantalla limpia:** ningún dato de otra persona, correo, chat ni ruta del computador.
3. **Recrear o grabar:** el estilo dice cuándo se recrea la interfaz y cuándo se graba la real. La grabación real queda para la prueba ("esto se hizo de verdad").
4. **Se muestra un componente recortado, no la pantalla entera,** con el texto de interfaz nunca bajo 36 px en el tamaño final y el cursor como actor cuando el espectador va a repetir el paso.
5. **Antes del render completo, el storyboard** (ver `SKILL.md`): un cuadro real de cada paso, en el lienzo, y el dueño lo aprueba.
6. Si va dentro de un reel, sigue `reel-hablado.md`. Si es largo, `largo.md`.

## Terminado cuando
- No se ve ningún dato privado en ningún cuadro.
- El texto de la interfaz se lee en el tamaño final.
- Lo que se dice que se hizo se ve hecho de verdad.
